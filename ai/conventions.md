# Conventions

## Mathematical conventions

- Use displayed equations with `$$ ... $$`.
- Use inline equations with `$...$`.
- State sign, phase, Fourier, and gauge conventions before using them.

## Citation conventions

- Use BibTeX keys from `literature/references.bib`.
- Do not cite papers that have not been inspected.
- Mark abstract-level claims as such.

## Simulation conventions

- Scratch simulations live under `simulations/scratch/YYYY-MM-DD-slug/`.
- Use fixed seeds where randomness appears.
- Keep parameters in a small text file, preferably `params.yaml`.
- Record how to rerun the simulation in its `README.md`.
